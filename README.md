## 当前统计

当前工作区的 `main/config/taxonomy_v3.json` 经2026年11月18日审校，包含23个一级、236个二级、456个三级、634个四级节点和1396条五级路径（其中1条为人工复核）。[建设报告](12345热线五级分类体系建设报告.md)采用这一版统计；[技术报告](分类体系构建依据与数据驱动优化报告.md)记录2026年10月29日研究版的869条路径，属于历史阶段，不是当前 v3 的数量。实际推理使用的版本由 `main/config/config.json` 决定。
