人民网 领导留言板 北京市数据采集说明
====================================
采集时间: 2026-10-29
数据来源: 人民网 领导留言板 公开页面/公开接口
采集范围: 北京市市委书记、市长; 除东城区外的各区区委书记、区长; 北京经济技术开发区书记、主任。
留言类型: 建言、投诉/求助、咨询三种全部采集。
东城区: 按要求跳过。
记录数: 11018 条 (按留言ID去重)
其中: 建言 758 条; 投诉/求助 8803 条; 咨询 1457 条。
层级: 市级 4202 条; 区级 6816 条。

文件说明
--------
1. 北京市领导留言板_各区书记区长_建言投诉求助咨询.xlsx
   主数据表, 含 留言明细/统计/采集说明 三个工作表。
2. 北京市领导留言板_留言明细.csv
   与Excel明细相同的数据, UTF-8-SIG编码, 可直接用Excel打开。
3. beijing_liuyan_crawler.py
   采集脚本, 支持断点续跑: 已完成的列表会缓存到 raw/lists, 不会重复抓取。
4. raw/
   原始接口数据缓存, 可用于复核或重新导出。

重要说明
--------
- 公开列表接口显示 timeSpan=2, 即页面当前可见范围约为近两年; 不是建站以来全部历史留言。
- 本次先完成留言列表主表, 包含留言正文、类型、领域、时间、办理状态、最新回复时间等。
- 回复单位/回复内容目前为空: 官方回复正文需要再逐条访问留言详情接口。由于站点有访问频率限制, 逐条抓取1万多条会耗时较长, 建议在需要时分批运行。
- 网络请求默认节流。请勿高并发抓取; 仅用于学习研究并注明来源。

如需补抓回复正文
----------------
在脚本目录打开 PowerShell, 运行:
  python beijing_liuyan_crawler.py --outdir raw --output 北京市领导留言板_含回复.xlsx --delay 5
脚本会复用已有列表缓存, 只补详情; 中断后重新运行可继续。
